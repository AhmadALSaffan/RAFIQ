# Getting help with Rafiq

## Install

Download the latest installer, `Rafiq_x.y.z_x64-setup.exe`, from [Releases](https://github.com/AhmadALSaffan/RAFIQ/releases/latest) and run it. Rafiq updates itself after that.

Requirements: Windows 10 or 11 (64-bit). For GitHub Copilot, a GitHub account with an active Copilot plan (Copilot Free works).

## Connect GitHub Copilot

1. Open **Settings → Connected accounts → GitHub Copilot → Connect**.
2. Rafiq shows a short code. Enter it at [github.com/login/device](https://github.com/login/device) and approve **Rafiq**.
3. Open **Models**, add a Copilot model, and start a chat.

You sign in once: Rafiq renews the sign-in on its own.

## Something isn't working

- **Read the in-app guide:** the **How Rafiq works** page in the sidebar.
- **Common questions:** see the [FAQ](https://github.com/AhmadALSaffan/RAFIQ#readme).
- **Report a bug or ask a question:** [open an issue](https://github.com/AhmadALSaffan/RAFIQ/issues/new). It helps to attach the diagnostics report from **Settings → Cost → Save report**. It contains your app version and settings, never your keys or your chats.

## Security

To report a security problem, please don't post the details in a public issue. Open an issue that only says you have a security report, and the developer will arrange a private channel.
