# PREFLIGHT — run before showing any design

Answer each with yes/no. Any "no" is a fix, not a note.

## Decision
- [ ] I can name the one dominant trait (dense / calm / loud / warm / precise).
- [ ] The one primary action per view is obvious and is the only thing in the accent colour.

## Type
- [ ] ≤ 4 font sizes, exactly 2 weights, ≤ 2 families.
- [ ] Body 15–18px; Arabic line-height ≥ 1.6; line length 45–75 (ar 35–60) chars.
- [ ] No gradient text, no text-shadow, no ALL CAPS beyond two words, no fake-bold Arabic.

## Colour
- [ ] No purple/pink/blue gradient anywhere. No glass panels. No glow behind cards.
- [ ] One neutral ramp + one accent + red/green only.
- [ ] Muted text contrast ≥ 4.5:1 in both themes. Dark mode is a palette, not an inversion.

## Layout
- [ ] Cards only where items are compared or acted on; settings/text/forms are not cards.
- [ ] No icon-in-rounded-square feature grid. No three-button hero. No fake browser mockup.
- [ ] Spacing on the grid; sections clearly separated; nothing floats in dead space.
- [ ] Works at 375px width with 16px gutters and no horizontal scroll.
- [ ] RTL uses logical properties; icons that imply direction are mirrored; logos/code are not.

## Copy
- [ ] No banned words (unlock, empower, seamless, effortless, elevate, leverage, revolutionize, delve…).
- [ ] No "Welcome to", no rhetorical-question headline, no exclamation marks, no emojis in UI.
- [ ] Buttons are verb + object. Headline names a concrete outcome. At least one real number or name.
- [ ] Not three identical bold-label bullets. Sentences vary in length.

## Motion
- [ ] Every animation reveals a state change or preserves context; nothing decorative loops.
- [ ] 120–400ms, ease-out, honours prefers-reduced-motion.

## Specificity
- [ ] Something on this screen could only belong to this product (real screenshot, real data, real sentence).
- [ ] If I deleted any element, information would be lost.
